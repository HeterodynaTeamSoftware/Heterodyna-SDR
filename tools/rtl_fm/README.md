# Opcjonalny silnik rtl_fm

Ten katalog celowo nie zawiera `rtl_fm.exe`, bibliotek DLL ani sterowników (pochodzą od innych autorów i mają własne licencje). Do sprzętowego testu RTL-SDR pobierz kompatybilny i zaufany pakiet RTL-SDR, sprawdź licencje i SHA-256, umieść `rtl_fm.exe` i wymagane przez niego DLL w tym katalogu. Adapter szuka go pod ścieżką `tools/rtl_fm/rtl_fm.exe`.

Nie jest wymagany do kompilacji, parserów, testów syntetycznych ani trybu demo. Nie pobieraj przypadkowych binarek z nieznanych stron.
