# Contributing to Heterodyna SDR / Protocol Lab

Dziękujemy za pomoc w rozwoju projektu. Kod źródłowy Protocol Lab jest licencjonowany na warunkach GNU GPL v3 (`GPL-3.0-only`). Przed zgłoszeniem Pull Request:

1. Zgłoś problem/ulepszenie przez GitHub Issues (jeśli możliwe).
2. Utwórz gałąź i wprowadzaj czytelne, ograniczone tematycznie zmiany.
3. Uruchom testy zgodnie z `INSTRUKCJA_KOMPILACJI_WINDOWS.md`; opisz, które testy wykonałeś i na jakim Windows.
4. Nie dodawaj EXE/DLL/PDB, danych użytkowników, surowych nagrań z wrażliwą treścią, haseł, sekretów ani nielegalnie pozyskanych bibliotek.
5. Potwierdź, że masz prawo do wkładu oraz że może on zostać rozpowszechniony na GNU GPL v3. Jeśli opierasz się na cudzym kodzie, podaj licencję i pochodzenie.
6. Zmiany przechodzą przegląd kodu i testy przed akceptacją do projektu. Nie ma gwarancji automatycznego włączenia PR.

Bezpieczeństwo: informacje o podatnościach zgłaszaj zgodnie z dokumentem `SECURITY.md` w repozytorium, nie przez publiczne Issue zawierające exploity i dane wrażliwe.
